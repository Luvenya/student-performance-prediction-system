## Project Description
This project aims to develop a machine learning-based system that predicts student performance and helps identify students who may be at academic risk, supporting timely intervention.

## Main Objectives
- Predict student performance.
- Identify students who may be at academic risk.
- Generate intervention recommendations.
- Develop an academic risk dashboard.
